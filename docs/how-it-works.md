# How Lucky Jet Predictor Works

This guide explains the public workflow of the **Lucky Jet Predictor** project and how users access the Telegram bot.

## Step 1 — Open the Telegram Bot

Open:

https://t.me/litluckyjetbot

Telegram may launch the mobile app, desktop app or web interface depending on the device.

---

## Step 2 — Start the Predictor Bot

Launch the bot through Telegram.

The available interface may provide access to predictor-related information, Lucky Jet Signals and project updates.

Users can review whatever project information is currently available through the bot.

The exact interface may change as new project versions are released.
